# 🚀 Bio - Priyanshu Kumar | Developer Portfolio & Link in Bio

An all-in-one, ultra-fast, mobile-first **"Link-in-Bio & Developer Portfolio Hub"** built with modern Glassmorphism, real-time project search, dynamic category filtering, 5 color themes, QR code sharing, and 1-tap WhatsApp contact integration.

## 🌟 Live Demo
👉 **[Live Bio Page](https://priyanshu-kumar-maurya.github.io/Bio/)**

---

## ✨ Features
- 📱 **Mobile-First & Ultra Responsive**: Designed specifically for Instagram in-app browser and mobile devices.
- 👤 **Profile Header**: Glowing avatar status (`🟢 Available for Projects`), verified badge, typing tagline animation, and social media links.
- ⚡ **Bento Highlight Actions**: 1-click Resume download, full portfolio access, WhatsApp direct chat, and email inquiry.
- 📂 **20+ Projects Showcase**: Real-time search bar + filter tabs (`Full-Stack Apps`, `E-Commerce`, `Games & Tools`, `Landing Pages`).
- 🎨 **5 Color Themes**: Cyber Violet, Electric Cyan, Emerald Matrix, Sunset Amber, and Minimal Dark.
- 📲 **QR Code & Native Share**: Instant QR code generator for sharing the profile link.
- 💬 **WhatsApp Quick Prompts**: Prefilled message templates for instant client inquiries.

---

## 🛠️ Built With
- **HTML5** & semantic markup
- **CSS3** (Glassmorphism, CSS Variables, Flexbox, Grid, Keyframe Animations)
- **JavaScript (Vanilla ES6+)** (Dynamic filtering, theme switcher, QR rendering, clipboard API)
- **Font Awesome 6** Icons & Google Fonts (`Plus Jakarta Sans`, `Outfit`, `JetBrains Mono`)
